# IRIS by ORVIA — website source

Static, deployment-ready website prototype based on the supplied IRIS commercial brief.

## Preview locally

Run any static web server from this folder, for example:

```bash
python -m http.server 8000
```

Then open http://localhost:8000/

## Before production launch

- Replace the placeholder sitemap host (`iris.example`) with the approved public domain.
- Connect the contact form to the approved ORVIA enquiry workflow.
- Add production analytics only after consent/privacy requirements are agreed.
- Verify each integration and publish evidence-led status labels.
- Wire `/login/` to the actual platform authentication only when accepted.
- Add final legal/privacy/cookie pages and approved company registration details.
